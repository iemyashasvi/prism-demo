Prism vs Direct Integration

Same payment flow, same processors, same browser SDK. Only the server differs. Open the two server files side-by-side — that's the entire demo.

Direct integration

server/normal/stripe.ts + server/normal/adyen.ts

Every connector is its own file.

  • Stripe → form-urlencoded body, Bearer auth, snake_case response
  • Adyen → JSON body, x-API-key header, camelCase response, requires merchantAccount
  • Adding a third connector = writing a third file from scratch
  • Stripe — direct
  • Adyen — direct

Prism integration

server/prism/checkout.ts

One payload, every connector.

  • Single let payload = {…} reused for every connector
  • Swap a connector by adding one line to the connectors map
  • Same shape across the 80+ connectors prism ships with
  • Stripe — via prism
  • Adyen — via prism

What to look at

  1. Open all four pages and run a test payment.
  2. Then open server/normal/stripe.ts, server/normal/adyen.ts, and server/prism/checkout.ts side-by-side. Look for the single payload in the one prism file vs the two separate normal files.
  3. In the prism file, imagine adding paypal: paypalConfig to the connectors map. That's the entire diff.
