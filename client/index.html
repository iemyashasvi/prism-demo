Prism vs Direct Integration

Same payment flow (client-authentication tokenization), same processors, same browser SDK. The only thing that changes between the two columns below is the server code. Open both columns side-by-side and compare.

Direct integration

Raw HTTP per Stripe/Adyen API docs — no SDK. Different hosts, different auth headers, different content types, different error shapes.

  • Stripe — direct server/normal/stripe.ts
  • Adyen — direct server/normal/adyen.ts

Prism integration

Uses hyperswitch-prism. One SDK, one shape, swap a config to swap connectors.

  • Stripe — via prism server/prism/stripe.ts
  • Adyen — via prism server/prism/adyen.ts

What to look at

  1. Open all four pages and run a test payment on each (test cards listed on each page).
  2. Then read the four server modules side-by-side. The two prism modules differ by one import; the two direct modules look nothing alike.
  3. Run wc -l server/normal/*.ts server/prism/*.ts for the headline.
